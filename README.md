## 🧭 Research Focus

- 🧠 **LLM Reasoning & Test-Time Compute** — verifier/PRM-guided search, scaling inference-time compute for autoregressive & diffusion LMs
- 🤖 **Agentic & Adaptive AI** — self-evolving multi-agent systems, dynamic trust/reputation modelling
- 🎯 **Reinforcement Learning** — reasoning & decision-making in non-stationary environments
- 📡 **Applied Generative ML** — diffusion models for wireless/signal estimation (5G+)

## 🚧 Current Work

| Project | Where | Details |
|---|---|---|
| **Adaptive test-time compute for LLM reasoning** | REAL Lab, OU | Verifier/PRM-guided reasoning, agentic RL controllers, trajectory-level search — autoregressive (`ICML'26`) & diffusion (`COLM'26`) language models |
| **Diffusion-based wireless estimation & nGRF** | Stanford AI Lab | Neural Gaussian Radio Fields + verifier-guided trajectory search for diffusion test-time scaling in channel prediction (`KDD'26`) |
| **Internet of Agents Platform** | Conoid.ai | Decentralized, self-evolving multi-agent platform — trust/memory-based team formation, secure HTTP agent-communication protocol |
| **Meta-thinking in LLM agents (survey)** | Independent | Survey on meta-thinking via multi-agent reinforcement learning — `IEEE TAI` (under review) |
